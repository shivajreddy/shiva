Welcome to my blog. This is my first post, and I want to talk about how I built this site.

## The Stack

I built this site with a few tools I really enjoy working with:

- **Next.js 15** with the App Router for the framework
- **Tailwind CSS v4** for styling
- **MDX** for writing blog posts (like this one!)
- **next-themes** for dark/light mode support
- **Shiki** for syntax highlighting

## Why a Terminal Theme?

As a software engineer, I spend most of my day in a terminal. There's something satisfying about the simplicity of a monospace font and a dark background. I wanted my personal site to reflect that aesthetic.

```typescript
const site = {
  theme: "terminal",
  font: "JetBrains Mono",
  darkMode: true,
  reason: "because terminals are cool",
};
```

## Writing with MDX

MDX lets me write markdown but also embed React components directly in my posts. For example, I can use callouts:

<Callout type="tip">
  MDX is a great way to write blog posts. You get the simplicity of Markdown
  with the power of React components.
</Callout>
